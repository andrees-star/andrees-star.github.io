Featured project: FinCrece

End-to-end BI/ML system built for a microfinance case study: exploratory portfolio analysis, K-Means client segmentation, geolocation-based advisor reassignment optimization, and a Power BI management dashboard.

Key results:

320 clients analyzed across 10 cities
89.5% reduction in average client–advisor distance (276.4 km → 30.0 km) via linear programming optimization
4 client segments identified via K-Means (High risk, Standard base, High value, Low risk)
Cali identified as highest-risk city (22.93% delinquency vs. 11.05% national average)
